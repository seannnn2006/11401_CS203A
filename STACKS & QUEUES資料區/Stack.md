# Stack (堆疊)

##  基本概念
- 一種 **線性資料結構**，遵循 **後進先出 (LIFO)** 的原則。  
- 特性：
  1. 元素的 **push (新增)** 和 **pop (移除)** 都在同一端進行，稱為 **top**。  
  2. 可想像成一疊盤子：你只能從最上方放入或取出盤子。  

---

## 🔹 常見操作
- **push(x)**：將元素 `x` 加入堆疊頂端。  
- **pop()**：移除堆疊頂端的元素。  
- **peek()**：查看堆疊頂端元素但不移除。  
- **isEmpty()**：判斷堆疊是否為空。  
- **isFull()**：判斷堆疊是否已滿。  

---

## 📊 時間複雜度
| 操作     | 時間複雜度 |
|----------|------------|
| push     | O(1)       |
| pop      | O(1)       |
| peek     | O(1)       |
| isEmpty  | O(1)       |
| isFull   | O(1)       |

---

## 📌 應用範例
- **函式呼叫堆疊 (Function Call Stack)**：程式執行時的呼叫紀錄。  
- **字串反轉**：利用堆疊將字元順序反轉。  
- **括號匹配檢查**：判斷程式碼或數學式中的括號是否正確配對。  
- **演算法**：DFS (Depth-First Search) 使用 Stack 來管理。
