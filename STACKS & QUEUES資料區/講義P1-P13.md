# 堆疊與佇列的情境分析

---

##  Scenario 1: Only Entrance for Input and Output (Stack)

- 假設 **index = 0** 作為 bottom。  
- 狀態判斷：
  - `top == 0` → Stack is empty (初始狀態)。  
  - `top == max_size - 1` → Stack is full (填滿)。  
- **Array storage expansion by realloc()**  
  - 只需修改 `max_size`，即可擴充容量。  

---

##  Scenario 2: One Entrance, One Exit (Queue)

- 若選擇 **a 為 front (左)**，**b 為 rear (右)**。  
- 初始狀態：
  - `front = -1`  
  - `rear = -1`  
- 狀態變化：
  - **enqueue(x)** → 將元素加入 `rear`。  
  - **dequeue()** → 從 `front` 移除元素。  
- 需處理 **環狀佇列 (circular queue)** 的邏輯，避免浪費空間。
