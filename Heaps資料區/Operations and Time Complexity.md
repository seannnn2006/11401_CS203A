#  堆 (Heap) 的基本操作與時間複雜度

| 操作 | 說明 | 時間複雜度 |
|------|------|------------|
| **insert(x)** | 插入新元素並恢復堆序性 (heap-order) | O(log n) |
| **extract_root()** | 移除根節點 (最大堆 → 最大值；最小堆 → 最小值) | O(log n) |
| **peek_root()** | 存取根節點 (最大或最小)，不移除 | O(1) |
| **build_heap(array)** | 將一陣列轉換成堆結構 | O(n) |
| **heapify(i)** | 針對某個節點 i 檢查並修正堆性質，常用於刪除或建堆過程 | O(log n) |
