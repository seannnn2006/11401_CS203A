# 為什麼堆中的順序代表優先權？

## 1. 優先權的定義
- 優先權代表某個元素的重要性或緊急性  
- 在 **Priority Queue (優先佇列)** 中，每個元素都有一個優先值  
- 數值越高 (或越低) 代表越重要，取決於使用 **最大堆 (Max-Heap)** 或 **最小堆 (Min-Heap)**

### 舉例
1. 急診病患：分級為 5 → 高優先權 (需立即處理)  
2. 作業系統：剩餘時間最短的程序 → 高優先權 (Shortest Job First)  
3. 網路封包：QoS 等級高 → 高優先權 (需優先傳送)  

---

## 2. Heap Order Property = Encoded Priority Rule
堆的順序性質 = 優先權編碼規則  

- 在堆結構中，每個元素的 **鍵值 (key value，如數字、權重、時間)** 被用來表示其優先權  
- 堆的順序性質其實就是 **優先權規則的編碼方式**

---

## 3. 最大堆 (Max-Heap) 與最小堆 (Min-Heap)

### 最大堆 (Max-Heap)
- **順序性質**：父節點 ≥ 子節點  
- **優先權解釋**：鍵值越大 → 優先權越高  
- **根節點**：最大鍵值 → 最優先處理  

### 最小堆 (Min-Heap)
- **順序性質**：父節點 ≤ 子節點  
- **優先權解釋**：鍵值越小 → 優先權越高  
- **根節點**：最小鍵值 → 最優先處理
