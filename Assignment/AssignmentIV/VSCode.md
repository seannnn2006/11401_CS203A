# Connect to GitHub with VSCode

## Prerequisites
- 安裝Visual Studio Code [Download VS Code here](https://code.visualstudio.com/)
- 安裝Git並在系統上完成設定 [Download Git here](https://git-scm.com/).
- GitHub帳號
- 開發平台:Windows

## Steps to Connect to GitHub

1. **在 VSCode 安裝 GitHub 擴充功能**
    - 打開VSCode
    - Go to the Extensions view by clicking on the Extensions icon in the Activity Bar on the side of the window.
    - 在搜尋欄輸入 "GitHub Pull Requests and Issues" 並安裝

2. **登入 GitHub**
    - 開啟Command Palette (Ctrl+Shift+P)
    - 輸入 `GitHub: Sign in` 並選擇
    - 完成GitHub帳號的驗證與授權

3. **複製Repository**
    - 在 VSCode 打開 Command Palette
    - 輸入 `Git: Clone`並選擇
    - 貼上 GitHub repository 的 URL
    - 選擇一個本機資料夾

4. **打開Repository**
    - 點選 Open，即可進行專案的開發
