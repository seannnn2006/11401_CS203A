#  Adjacency Matrix (鄰接矩陣) 筆記

## 1. 定義
- 鄰接矩陣是一個 **V × V** 的矩陣，用來記錄兩個頂點之間是否存在邊。  

---

## 2. 優點
1. **O(1) 邊查詢**：`matrix[u][v]` 可直接得到結果  
2. **實現簡單**：易於編程、易於可視化  
3. **適合稠密圖** (邊多)  
4. **適合需要快速存取的演算法** (如 Floyd-Warshall)  
5. **自然適合存儲加權圖的權值**  

---

## 3. 缺點
1. **O(V²) 空間複雜度**：即使邊少也要占用大量空間  
2. **對稀疏圖浪費空間**：多數現實世界的圖都是稀疏的  
3. **取得鄰居需掃描整行** → O(V)  
4. **動態插入或刪除頂點較困難**  

---

## 4. 適用場景
1. **稠密圖**  
2. **邊查詢速度要求高的圖**
