#  Adjacency Matrix vs Adjacency List 比較

| 面向 | Adjacency Matrix (鄰接矩陣) | Adjacency List (鄰接列表) |
|------|-----------------------------|---------------------------|
| **邊查詢效率** | O(1) | O(deg(v)) |
| **空間複雜度** | O(V²) | O(V+E) |
| **BFS/DFS 遍歷** | O(V²) | O(V+E) |
| **適用圖形** | 密集圖 | 稀疏圖 |
| **鄰居迭代效率** | O(V) | O(deg(v)) |
| **實作難度** | 簡單 | 中等 |
| **動態圖支援** | 困難 | 容易 |

---

##  整合觀察
- 若圖是 **稀疏的** → 使用 **鄰接列表 (Adjacency List)** 是最佳選擇  
- 若圖是 **密集的** → 使用 **鄰接矩陣 (Adjacency Matrix)** 更合適  
- **稀疏矩陣 vs 稀疏列表**：屬於資料結構層級的抽象概念  
- **鄰接矩陣 vs 鄰接列表**：屬於圖論中的具體實作方式
