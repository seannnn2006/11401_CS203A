# Tree vs Graph Traversal

## 1. Tree Traversal
- **DFS**：Preorder, Inorder, Postorder  
- **BFS**：Level-order  
- **基礎**：父子關係  
- **是否需要 visited[]**：不需要 (樹無環，天然避免重複)  

---

## 2. Graph Traversal
- **DFS**  
- **BFS**  
- **基礎**：鄰接關係 (Neighbor adjacency)  
- **是否需要 visited[]**：需要 (圖可能有環，必須避免重複或無限循環)  

---

## 3. 整合觀察
- **Graph Traversal = Tree Traversal + visited[]**  
- 在樹中，因為沒有環，所以不需要額外的 visited[]  
- 在圖中，因為可能有環，必須使用 visited[] 來避免重複或無限循環
