#  Graph 類型筆記

## 1. Connected Graph (連通圖)
- **定義**：所有節點彼此可達  
- **說明**：節點 0–3 之間有邊連接，形成一個整體，任意兩點間都有路徑  

---

## 2. Tree (樹)
- **定義**：無環、連通、有根  
- **說明**：節點 0 為根節點，向下分支至節點 1–6，形成層級結構  
- **特性**：樹是特殊的 **連通無環圖**  

---

## 3. Directed Graph (有向圖)
- **定義**：邊具方向性  
- **說明**：節點間的邊有箭頭，表示方向，例如 `0 → 1`，代表只能從 0 到 1  

---

## 4. Self Edge (自環邊)
- **定義**：邊連接自身  
- **說明**：單一節點有一條邊回到自己，常見於 **狀態機** 或 **遞迴結構**  

---

## 5. Multigraph (多重圖)
- **定義**：節點間可有多條邊  
- **說明**：節點間存在多條邊，例如 `1 ↔ 2` 有兩條邊，表示多種關係或通道
