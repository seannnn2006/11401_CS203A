# 樹的遍歷 (Tree Traversal)

---

##  深度優先遍歷 (Depth-First Traversal, DFT)

###  定義
- 沿著樹的分支盡可能深入，直到無法繼續，再回溯到上一層，繼續探索其他分支。  

###  常見形式
1. **先序遍歷 (Pre-order)**：根 → 左子樹 → 右子樹  
   - 用途：複製樹、建立樹的結構。  
2. **中序遍歷 (In-order)**：左子樹 → 根 → 右子樹  
   - 用途：適合 **BST 排序**。  
3. **後序遍歷 (Post-order)**：左子樹 → 右子樹 → 根  
   - 用途：刪除樹、釋放記憶體。  

###  實作方式
- 通常使用 **遞迴 (recursion)** 或 **堆疊 (stack)**。  

###  應用場景
- 表達樹的計算。  
- 回溯演算法。  
- 深度搜尋問題。  

---

##  廣度優先遍歷 (Breadth-First Traversal, BFT)

###  定義
- 先訪問同一層的所有節點，再進入下一層，逐層展開。  

###  常見形式
- **層序遍歷 (Level-order)**：從根開始，逐層依序訪問。  

###  實作方式
- 通常使用 **佇列 (queue)**。  

###  應用場景
- 找最短路徑。  
- 層次分析。  
- 廣度搜尋問題。
