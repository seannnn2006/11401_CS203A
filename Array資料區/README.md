# Array資料區 

本資料夾包含 11401_CS203A 課程中與陣列（Array）相關的學習筆記。

##  檔案說明

| 檔案名稱       | 說明                     |
|----------------|--------------------------|
| `Array`        | 基本陣列操作與相關內容     | 
| `Array(Bonus)` | 陣列進階內容      | 

##  學習目標

- 熟悉 C/C++ 中陣列的宣告與使用方式
- 練習陣列的遍歷、搜尋、排序等基本操作
- 挑戰進階題目以強化邏輯思維與程式設計能力

##  Big O 分析

| 操作類型       | 時間複雜度 | 空間複雜度 | 備註                     |
|----------------|------------|------------|--------------------------|
| 訪問元素       | O(1)       | O(1)       | 透過索引直接存取         |
| 線性搜尋       | O(n)       | O(1)       | 須逐一比對每個元素       |
| 二分搜尋       | O(log n)   | O(1)       | 陣列需先排序             |
| 插入（中間）   | O(n)       | O(1)       | 需移動後續元素           |
| 刪除（中間）   | O(n)       | O(1)       | 同樣需移動後續元素       |
| 排序（Bubble） | O(n²)      | O(1)       | 適合小型資料測試         |

註：以上複雜度分析以靜態陣列為主，動態陣列（如 C++ vector）可能略有不同。
