# 📘 Hash Table 基本概念

## 1. 重要元素
1. **Key**：用來辨識資料的唯一標籤，通常由 Value₁ 經由 hash function `f(Value₁)` 計算出 index  
2. **Value₂**：實際要儲存或查詢的資料內容，是我們關心的資訊本體  
3. **Computed Index**：由 `f(Value₁)` 計算出的整數索引，用來決定資料在 Hash Table 中的位置  
4. **Collision**：多個不同的 Value₁ 經由 `f()` 映射到相同的 Index，導致資料重疊  
5. **Goal**：確保 key 的唯一性，並能高效查詢、插入、刪除對應的 Value₂  

---

## 2. 運作流程
🔄 **Key → Hash Function → Index → Value₂**  
Key 經由 hash function 推導出 Hash Value  

---

## 3. Key Concept
1. **Hash Table**：一種陣列結構，用來儲存 Key-value pair，支援快速查詢、插入、刪除操作  
2. **Key**：使用者提供的識別值 (例如：學號、帳號)，用來定位資料  
3. **Hash Function**：將 key 轉換成整數 index，決定資料在 Hash Table 中的儲存位置  
4. **Collision**：當兩個不同的 key 經由 hash function 映射到相同 index 時發生碰撞  
5. **Load Factor (α)**：表示表格的使用率  
   \[
   \alpha = \frac{\text{元素數量}}{\text{表格大小}}
   \]  
   用來衡量 Hash Table 的飽和程度
