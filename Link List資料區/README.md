# Link List資料區 

本資料夾收錄 CS203A 課程中與 Linked List（鏈結串列）相關的學習筆記與程式範例，包含基本操作、概念比較與進階思考內容。

##  檔案一覽

| 檔案名稱                   | 說明                                   | 
|----------------------------|----------------------------------------|
| `Link List`                | 基本 Linked List 操作程式              | 
| `Insert`                   | 插入節點的實作                         | 
| `Delete`                   | 刪除節點的實作                         | 
| `Bonus`                    | 較有挑戰的內容                             |
| `Array vs. Linked List`    | 比較陣列與鏈結串列的差異               | 
| `Linked List類型比較`     | 單向、雙向、循環串列的差異分析         | 
| `Trade-offs in Linked List`| 討論使用 Linked List 的優缺點          |
| `值 VS 指標`              | 探討值傳遞與指標傳遞的差異             |

##  學習目標

- 掌握 Linked List 的基本結構與操作方式
- 理解陣列與鏈結串列的使用情境與效能差異
- 熟悉節點插入、刪除的程式邏輯
- 探索不同類型的 Linked List（單向、雙向、循環）
- 強化指標操作與記憶體管理的觀念
