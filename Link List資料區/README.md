##  學習目標

- 掌握 Linked List 的基本結構與操作方式
- 理解陣列與鏈結串列的使用情境與效能差異
- 熟悉節點插入、刪除的程式邏輯
- 探索不同類型的 Linked List（單向、雙向、循環）
- 強化指標操作與記憶體管理的觀念

##  Big O 快速查詢

| 操作類型           | 時間複雜度 | 空間複雜度 | 備註                                   |
|--------------------|------------|------------|----------------------------------------|
| 訪問元素（隨機）   | O(n)       | O(1)       | 必須從頭開始遍歷                       |
| 訪問元素（頭節點） | O(1)       | O(1)       | 直接存取 head                          |
| 插入（頭節點）     | O(1)       | O(1)       | 修改指標即可                           |
| 插入（尾節點）     | O(1) 或 O(n)| O(1)      | 若有尾指標為 O(1)，否則需遍歷 O(n)    |
| 插入（中間位置）   | O(n)       | O(1)       | 需遍歷找到插入點                       |
| 刪除（頭節點）     | O(1)       | O(1)       | 修改 head 指標即可                     |
| 刪除（尾節點）     | O(n)       | O(1)       | 需遍歷找到前一個節點                   |
| 刪除（中間位置）   | O(n)       | O(1)       | 需遍歷找到刪除點                       |
| 搜尋元素           | O(n)       | O(1)       | 必須逐一比對                           |

註：Linked List 的操作效率取決於是否有額外指標（如 tail），以及是否為單向、雙向或循環串列。
