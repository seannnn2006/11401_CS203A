# 陣列 vs. 鏈結串列

## 基本比較

| 面向         | 陣列 (Array)                          | 鏈結串列 (Linked List)                          |
|--------------|---------------------------------------|------------------------------------------------|
| 記憶體配置   | 連續的記憶體區塊                      | 非連續，每個節點動態配置                        |
| 大小彈性     | 固定大小                              | 動態大小，可在執行時增減                        |
| 存取方式     | 直接透過索引存取 → O(1)               | 只能從頭開始逐一存取 → O(n)                     |
| 插入／刪除效率 | 成本高 → 需搬移元素 → O(n)            | 若已知節點指標 → O(1)                           |
| 記憶體使用   | 無額外負擔（只儲存資料）              | 每個節點需額外儲存指標（如 next，有時還有 prev） |
| 快取效能     | 較佳 → 記憶體連續，快取命中率高       | 較差 → 節點分散，快取命中率低                   |
| 實作難易度   | 較簡單，容易撰寫與使用                | 較複雜，需處理指標與記憶體管理                  |
| 適用情境     | 適合資料大小已知，且需頻繁隨機存取    | 適合資料大小不固定，且需頻繁插入／刪除          |

---

##  操作時間複雜度比較

| 操作           | 陣列 (Array) | 鏈結串列 (Linked List) |
|----------------|--------------|------------------------|
| 索引存取       | O(1)         | O(n)                   |
| 搜尋元素       | O(n)         | O(n)                   |
| 插入至開頭     | O(n)         | O(1)                   |
| 插入至中間     | O(n)         | O(n)                   |
| 插入至尾端     | O(1)         | O(n)，若有 tail pointer → O(1) |
| 刪除           | O(n)         | O(n)，若已知節點指標 → O(1)   |
